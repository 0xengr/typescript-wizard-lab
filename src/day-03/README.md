# Day 3 — Narrowing and safe data handling

Run only this day: `bun run test:day-03`

## How to use this day
1. Read each exercise header.
2. Implement the function/type in the same file.
3. Run `bun run test:day-03`.
4. Fix compiler and test feedback.

## Exercises
1. `status-renderer.ts` — discriminated unions and exhaustive checks
2. `api-result.ts` — result types and narrowing
3. `type-guards.ts` — custom type guards
4. `nullable-access.ts` — optional chaining and nullish coalescing
5. `runtime-validation.ts` — runtime vs compile-time types

## Tips
- Discriminate on a common property.
- Validate runtime data before trusting it.
- Use type guards to narrow unknown values.
