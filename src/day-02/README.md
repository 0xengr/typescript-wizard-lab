# Day 2 — Functions and type composition

Run only this day: `bun run test:day-02`

## How to use this day
1. Read each exercise header.
2. Implement the function/type in the same file.
3. Run `bun run test:day-02`.
4. Fix compiler and test feedback.

## Exercises
1. `function-contracts.ts` — parameters, returns, defaults
2. `operation-runner.ts` — function types and higher-order functions
3. `config-variants.ts` — unions, intersections, literals, satisfies
4. `unknown-parser.ts` — any, unknown, never
5. `status-literals.ts` — literal types and as const

## Tips
- Narrow unknown values before use.
- Prefer explicit return types for public functions.
- Use `as const` to preserve literal types.
