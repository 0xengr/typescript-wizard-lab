# Day 5 — Modules, classes, and composition

Run only this day: `bun run test:day-05`

## How to use this day
1. Read each exercise header.
2. Implement the class/function in the same file.
3. Run `bun run test:day-05`.
4. Fix compiler and test feedback.

## Exercises
1. `invoice.ts` — classes and access modifiers
2. `payment-processor.ts` — interfaces and dependency injection
3. `order-service.ts` — composition
4. `structural-typing.ts` — structural compatibility
5. `module-boundaries.ts` — pure domain logic

## Tips
- Inject dependencies through constructors.
- Keep domain logic free of infrastructure.
- Prefer composition over inheritance.
