# Day 4 — Generics and type manipulation

Run only this day: `bun run test:day-04`

## How to use this day
1. Read each exercise header.
2. Implement the function/type in the same file.
3. Run `bun run test:day-04`.
4. Fix compiler and test feedback.

## Exercises
1. `identity-and-first.ts` — generic functions
2. `typed-repository.ts` — constraints and keyof
3. `property-access.ts` — indexed access types
4. `user-updates.ts` — utility types
5. `record-transforms.ts` — Record, Readonly, ReturnType

## Tips
- Constrain generics only when needed.
- Preserve input objects by returning copies.
- Use utility types to derive new shapes.
