# Day 1 — TypeScript foundations

Run only this day: `bun run test:day-01`

## How to use this day
1. Read each exercise header.
2. Implement the function/type in the same file.
3. Run `bun run test:day-01`.
4. Fix compiler and test feedback.
5. Run `bun run typecheck`.

## Exercises
1. `type-inference.ts` — inference and explicit annotations
2. `user-profile.ts` — interfaces, optional and readonly properties
3. `product-catalog.ts` — type aliases and object shapes
4. `coordinates.ts` — readonly tuples and immutability
5. `strict-settings.ts` — optional properties and defaults

## Tips
- Start with types, then implementation.
- Handle empty arrays and missing values.
- Keep functions pure where possible.
