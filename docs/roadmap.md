# Seven-Day Roadmap

## Day 1 — TypeScript foundations
Type inference, annotations, primitives, arrays, type aliases, interfaces, optional/readonly properties, strict config.

Exercises: type-inference, user-profile, product-catalog, coordinates, strict-settings.

## Day 2 — Functions and type composition
Function params/returns, optional/default, function types, unions, intersections, literals, any/unknown/never, satisfies.

Exercises: function-contracts, operation-runner, config-variants, unknown-parser, status-literals.

## Day 3 — Narrowing and safe data handling
typeof/in/instanceof, discriminated unions, type guards, exhaustive checks, nullable, runtime validation.

Exercises: status-renderer, api-result, type-guards, nullable-access, runtime-validation.

## Day 4 — Generics and type manipulation
Generics, constraints, keyof, indexed access, typeof in types, utility types.

Exercises: identity-and-first, typed-repository, property-access, user-updates, record-transforms.

## Day 5 — Modules, classes, composition
ES modules, classes, access modifiers, structural typing, composition, DI.

Exercises: invoice, payment-processor, order-service, structural-typing, module-boundaries.

## Day 6 — Async and boundaries
Promises, async/await, typed returns, errors, DTOs, runtime validation, DI for tests.

Exercises: fetch-user, retry, dto-mapping, boundary-validation, result-error-handling.

## Day 7 — Integration
Combine prior concepts in a task-processing challenge, refactor, type safety, edge cases, full suite.

Exercise: task-pipeline (unsolved).
